# Королевство

Браузерная пиксельная 2D-микростратегия по мотивам **Kingdom Two Crowns**. Вы — монарх на коне: собираете монеты, нанимаете подданных, строите стены и башни, а ночью отбиваетесь от Жадности. Механики повторяют оригинал: числа и правила собраны в [спецификацию](docs/mechanics.md). Графика, звук и музыка созданы кодом с нуля: никаких файлов из оригинальной игры.

Игра работает на компьютере и на телефоне (в горизонтальной ориентации), сохраняется в браузере и собирается в один HTML-файл.

**Играть:** https://claude.ai/artifact/JH7yo1fXPpGXMVLkR83rou — ссылка приватная: откроется в аккаунте владельца или у тех, кому он её расшарит.

## Как играть

**Цель кампании** — взорвать пещеры Жадности на всех пяти островах.

- Бросьте монету бродяге — он станет крестьянином.
- Купите лук, молот или косу — крестьянин станет лучником, строителем или фермером.
- Держите кнопку оплаты у постройки — монеты лягут в слоты над ней.
- Ночью приходит Жадность. Каждый удар выбивает у монарха монету, а без монет слетает корона.
- Потеряли корону — правление продолжит наследник. Всё, что открыто за самоцветы, разрушенные порталы и вклад в банке сохранятся.

### Управление

| Действие | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Ехать | A/D или ←/→ | стик, крестовина | тянуть пальцем в сторону |
| Галоп | держать Shift (или дважды нажать направление) | триггер | довести палец до края экрана |
| Уронить монету | коротко S / ↓ / пробел | A | тап по монарху или свайп вниз |
| Платить | держать S / ↓ у постройки | держать A | свайп вниз и держать |
| Способность скакуна | W / ↑ или Shift стоя | — | свайп вверх |
| Пауза и карта | Esc / P | Start | кнопка ❚❚ в углу |

**Кооператив «две короны»:** в паузе выберите «Второй игрок». Первый играет на WASD + левый Shift, второй — на стрелках + правый Shift. Экран делится на две половины.

## Что реализовано

- **Монарх и скакуны:** шаг и галоп с выносливостью, выпас и бафф «сытость». Восемь скакунов со способностями: грифон, олень, тяжеловоз, боевой конь, медведь, ящер, единорог.
- **Кошелёк:** 40 монет, переполнение до 50. Самоцвет занимает три места. Монеты падают на землю или в реку.
- **Оплата слотами:** 5 монет в секунду. Если отпустить кнопку раньше, монеты высыпаются.
- **Городской центр:** 7 тиров, от костра до Железной крепости, с перезарядкой между улучшениями.
- **Стены и башни:** 5 и 6 уровней. Прочность, ремонт строителями, отстройка после разрушения.
- **Подданные:**
  - бродяги в лесных лагерях и крестьяне;
  - лучники: охотятся днём, ночью стоят у стен и на башнях;
  - строители: очередь заказов, ремонт, вырубка леса;
  - фермеры: колодцы, мельницы и ягоды;
  - оруженосцы и рыцари: монеты служат им бронёй, водят отряды на порталы;
  - пикинёры: ловят рыбу.
- **Жадность:** гридлинги (в масках крепче), летуны, гиганты-плодители, похитители короны. Крадут монеты, инструменты и корону, ломают стены, горят на солнце.
- **Время:** сутки 4 минуты, 4 сезона по 16 дней, зима. Раз в сезон — Кровавая луна, после неё тихая ночь.
- **Волны по формулам оригинала:** активные порталы, защитники портала при атаке, ответная волна с затмением.
- **Экономика:** торговец с ослом, банкир с процентами, сундуки, Хранитель самоцветов.
- **Особые постройки:**
  - статуи-благословения;
  - отшельники: баллиста, пекарня, башня рыцарей, стена с рогом, конюшня;
  - осадные мастерские и катапульты;
  - телепорты, дома горожан.
- **Острова:** 5 островов, лодка из 59 деталей, маяк, переправа с командой, распад покинутых островов. Технологии: каменоломня (камень) и железный рудник (железо).
- **Финал острова:** бомба, пещера с гнёздами и взрыв, зачищающий остров.
- **Сопутствующее:** призрак прежнего правителя с подсказками, собака, зимний кабан.
- **Картинка:**
  - пиксель-арт в низком разрешении;
  - пять слоёв леса с воздушной перспективой;
  - отражения в воде с рябью;
  - ночное освещение от костров и факелов;
  - дождь, снег и туман.
- **Звук:** всё синтезируется WebAudio — эффекты, ветер, река, птицы, сверчки и генеративная музыка.
- **Сервис:** титульный экран, пауза с картой островов, пять уровней сложности, автосохранение каждое утро.

## Разработка

Нужен Node.js 20+.

```bash
npm install
npm run dev        # игра на http://localhost:5173
npm test           # автотесты механик и симуляция кампании
npm run typecheck  # проверка типов
npm run build      # сборка в один файл dist/index.html
npm run build:artifact  # страница для публикации ссылкой: dist/korolevstvo.html
```

Параметры адреса для отладки:

| Параметр | Что делает |
|---|---|
| `?play=1` | начать игру сразу, без титульного экрана |
| `?setup=defense` / `army` / `stone` | готовое королевство со стенами и войском |
| `?phase=0.7&day=15` | время суток (0 — рассвет) и номер дня |
| `?island=3` | сразу на указанный остров |
| `?speed=4` | ускорить время |
| `?coins=30` | монеты в кошельке |
| `?nosave=1` | не сохранять |

### Устройство проекта

```
src/engine   экран, игровой цикл, ввод, звук, шрифт, спрайты
src/render   небо, слои леса, земля, вода, свет, частицы, погода
src/art      процедурный пиксель-арт: кони, люди, Жадность, постройки
src/game     мир острова, сущности, постройки, волны, кампания, сохранения, бот
src/ui       интерфейс: кошелёк, слоты оплаты, меню, карта
tests        автотесты механик, кампании и долгой симуляции
docs         спецификация механик оригинала
```
